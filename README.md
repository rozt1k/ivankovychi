# Сайт котеджного містечка в Іванковичах — концепти

Статичні сторінки без фреймворків. Відкрийте `index.html` у браузері.

- `index.html` — сторінка вибору з трьома прев'ю.
- `concept-1.html` — «Мінімал», повна версія сайту (`css/style.css`, `js/main.js`).
- `concept-2.html` — «Вечір», темний преміум (`css/concept-2.css`, `js/concept-2.js`).
- `concept-3.html` — «Креслення», архітектурний (`css/concept-3.css`, `js/concept-3.js`).

У концептах 2 і 3 зверстано перші екрани, «Про квартал», генплан, будинки й коротку форму. Решту розділів доробимо в обраному стилі.

## Плашка «Концепт 1 · 2 · 3»

Це `js/switcher.js`. Для фінального сайту видаліть рядок `<script src="js/switcher.js" defer></script>` з HTML.

## Заглушки, які треба замінити

1. **Телефон і пошта** — `+380 00 000 00 00`, `+380000000000`, `info@example.com`.
2. **Статуси ділянок** — масив `LOTS` у JS кожного концепту: `status: 'free' | 'reserved' | 'sold'`.
3. **Форма заявки** — у концепті 1 задайте `FORM_ENDPOINT` у `js/main.js`; у концептах 2 і 3 форма лише демонструє повідомлення.
4. **Площі будинків і ціни** — у візуалізаціях їх не було.

## Ресурси

- `img/` — WebP із «Комплекту візуалізацій КМ Іванковичі» та фото фасадів; `c3-plan-*` — креслення з обкладинки комплекту.
- `fonts/` — Geologica, Cormorant Garamond, Unbounded (усі SIL Open Font License 1.1), підключені локально.
